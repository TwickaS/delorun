- A plugin switched off in Plugins switches back on. A third-party plugin whose bundle only adds a setting to a row Delorun protects, as `dsh-unlag` adds `base` to the reload row, switched off without complaint and was then refused as `management-required` each time it was switched on, although Plugins showed it as not protected. Both directions now judge the same thing: a change may add a setting to a protected row and may not disable the row, replace it, drop it, give its id to another row, or change or remove a setting the profile ships for it.
