- **Your own browser** is a new optional pack: in a chat where you allow it, the agent works in your own Chrome, signed in as you, through browse. It carries Delorun's own copy of browse, which never updates itself, and its browser row starts off.
- Until Chrome is paired, the row reads "Needs setup · Connect Chrome" with the steps: add the browse extension, select **Get a pairing code** and enter the code in the extension. The code comes from the computer only.
- A skill teaches the agent to work in your browser carefully: read the page first, hand sign-ins, codes and payments back to you, and close the tabs it opened.
