- The recovery screen, which opens when the studio will not start, has **Roll back** next to Start in safe mode. It goes back to the release before the last update and says first that chats made since are set aside, not deleted; when the update took no copy of your chats it offers to go back with your settings only. It needs you at your computer, and a rollback waits for running chats to finish before Delorun restarts. **Leave safe mode** ends safe mode from the same screen.
- Settings → Changes starts and ends safe mode with a button, so safe mode no longer needs a terminal. Starting it changes nothing until Delorun next starts.
- Settings → Trash lists **Set aside by a rollback**: the chats a rollback moved out of use and the chat copies an update took, with their sizes. Each has a Remove button that asks first and, from a phone, needs the unlock you entered on it. Delorun never removes them on its own, and refuses to remove a copy a rollback of the last update still needs.
