# Delorun 0.1.0-rc.3

Delorun 0.1.0-rc.3 is the third release candidate of Delorun, the community fork of DeepSeek Harness. It is based on DeepSeek Harness `dsh-v0.2.2-rc.3`, as rc.2 was. The sections after the highlights list every change by area.

## Highlights

- **Update notices in the studio.** When a newer release is out, the sidebar now shows a notice with its version and a What's new link, and Settings → General → Updates turns the daily check off and on. Only the computer itself can turn the check off; an approved phone cannot.
- **A trust badge that says what was checked.** The sidebar's trust badge reads what Delorun checked at start, instead of "Unknown", until you choose Check now.
- **A tidier first step.** Setup no longer lists a DeepSeek Account provider that Delorun does not offer.

## Platforms

Delorun 0.1.0-rc.3 runs on Linux (x64 and arm64) and on Windows through WSL2, as rc.2 did.

## Upgrading from 0.1.0-rc.2

Run `delorun update`. The studio of rc.2 cannot show the update notice, so this one update is announced only in the terminal and by `delorun update --check`; from rc.3 on, the sidebar shows the next one. Your chats, workspaces, settings, plugins and approved devices carry over, and nothing needs changing by hand. If the new version fails its health check, Delorun goes back to rc.2 on its own, and `delorun recover rollback` takes you back at any time.

## Setup
- **Fixed:** The first setup step no longer lists "DeepSeek Account" among your model providers. Delorun has no DeepSeek account sign-in, so the row could only ever say there was no free test for it. Your own DeepSeek API key is still listed and tested.

## Studio
- **Fixed:** The trust badge in the sidebar no longer reads "Unknown" for a release that verifies. The studio now reads your plugins and your changes when it starts, as `delorun verify` does, so the badge shows what was checked at start until you choose Check now.
- **Fixed:** The sidebar shows the update notice when a newer release exists, and the Check for new releases switch in Settings works, instead of both staying idle.
