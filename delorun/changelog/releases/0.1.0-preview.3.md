# Delorun 0.1.0-preview.3

## Install and update
- An install, `delorun update`, `delorun repair` and a plugin pack download show a live bar with size, speed and time left, then a checklist with a tick and a time for each step. A log or a pipe gets one plain line per step and one line for each tenth of a download.
- The source code moved to github.com/twickas/delorun; the old address redirects.

## Setup
- Every add in the setup guide shows in the downloads panel, including a plugin the plugin manager installs from npm and the browser download Browser needs; those two show in the tab that started them, with a bar that moves until the size is known.
- A plugin card being added shows a full-width bar and one quiet line: its place in the queue, then the percentage with the speed and time left, then checking and installing. The Browser step shows the same.
- Recommended plugins no longer offers the Browser pack beside the Browser step, and the packs for Claude Code and Codex hooks, already installed Claude Code or Codex, and your own Chrome have titles that read apart from the Agents and Browser steps.
- Recommended plugins in the setup guide lists each plugin the way the plugin market does: its artwork in a frame, the title, the description with More, what it fits in a quiet line under it, and Add at the end of the row. Adding works as before, with the download under the description and the same row in the downloads panel.
- `delorun setup` is short: one privacy line, then "Use Delorun from your phone too?", then, only if you have DeepSeek Harness chats, whether to copy them, and then it starts Delorun and opens the studio. The studio's welcome screen asks for your model key. The "How will you use Delorun?" question and the review screen are gone.
- Setup picks the studio port itself: it takes 3080, or the next free port and says so. How much Delorun asks, running in the background, the profile name and phone access are in Settings → General → How Delorun runs, each with the `delorun setup` command that changes it.
- The first start runs in the terminal; Ctrl+C stops it, and `delorun start --background` keeps it running after the terminal closes. Setup ends by asking whether to keep the `delorun` command.
- A run without a terminal, or with `--yes`, asks nothing and takes safe defaults. `--phone` turns on phone access, `--import-dsh` copies your DeepSeek Harness chats, and `--port <n>` sets the studio port.
- Turning phone access off in Settings signs every paired device out and keeps the paired list; each device signs in again when you turn access on. The studio port refuses the ports web browsers block and the port phone access listens on, and a prompt change tells you to restart when the profile has hot reload off.
- **Fixed:** The end of setup no longer tells someone who ran `npx delorun` that their version "is not on the npm registry" and offers a package file that does not exist; it offers `npm install -g delorun@<version>`. Setup names the phone-pairing step only when you chose remote access.
- **Fixed:** Setup's privacy note and release-check question name releases.delorun.com and GitHub for the release check when you ran Delorun from npm, instead of describing it as a launcher built for another release channel.

## Studio
- The setup guide's plugin cards and the downloads panel show a download's speed and, once its size is known, the time left, measured the same way as the terminal's install display. A download that stands still shows no speed.
- The docs sidebar groups pages for people using Delorun and people building on it; old page addresses redirect.
- The docs sidebar and phone drawer end in one compact row: the language picker and a theme button that names the current theme. The site is now called Delorun Docs.

## Chats and workspaces
- **Fixed:** Importing DeepSeek Harness chats no longer prints a MaxListenersExceededWarning for large chat logs.

## Safety and privacy
- The privacy page names the publisher, the footer reads "Published by Delorun", and the licence files and the SBOM name Delorun instead of "Delo Run"; the first-run notice no longer names a maintainer.

## From upstream
- Based on DeepSeek Harness `dsh-v0.2.2-rc.3`.
