# Delorun 0.1.0-preview.3

## Install and update
- Container images are published at ghcr.io/twickas, and the plugin catalogue lives at github.com/TwickaS/delorun-plugins.
- An install, `delorun update`, `delorun repair` and a plugin pack download show a live bar with size, speed and time left, then a checklist with a tick and a time for each step. A log or a pipe gets one plain line per step and one line for each tenth of a download.
- The `delorun` package page on npm says what Delorun is, what the launcher needs, and links to the website, the docs and the issue tracker.
- The source code moved to github.com/twickas/delorun; the old address redirects.
- **Security:** Release root 2 lists the keys allowed to sign a release's log entry, ECDSA P-256 first and Ed25519ph as the alternative, and the logs whose checkpoints count. Delorun accepts a log entry only when a key the root lists for its type signed it, in a listed log cosigned by a listed witness, and verifies no release under a root without these lists, so a log that stops accepting one key type, or a new log shard, needs a root rotation by the offline root key and no client release. An earlier log listed after such a rotation verifies only the releases up to its last one, and a locally built 0.x release keeps installing under later roots that follow from root 2 and keep its targets key. Copies on 0.1.0-preview.2.7 or earlier cannot read root 2: reinstall once with `npx delorun@latest`; your home, chats and settings stay.

## Setup
- Every add in the setup guide shows in the downloads panel, including a plugin the plugin manager installs from npm and the browser download Browser needs; those two show in the tab that started them, with a bar that moves until the size is known.
- A plugin card being added shows a full-width bar and one quiet line: its place in the queue, then the percentage with the speed and time left, then checking and installing. The Browser step shows the same.
- Recommended plugins no longer offers the Browser pack beside the Browser step, and the packs for Claude Code and Codex hooks, already installed Claude Code or Codex, and your own Chrome have titles that read apart from the Agents and Browser steps.
- Recommended plugins in the setup guide lists each plugin the way the plugin market does: its artwork in a frame, the title, the description with More, what it fits in a quiet line under it, and Add at the end of the row. Adding works as before, with the download under the description and the same row in the downloads panel.
- `delorun setup` is short: one privacy line, then "Use Delorun from your phone too?", then, only if you have DeepSeek Harness chats, whether to copy them, and then it starts Delorun and opens the studio. The studio's welcome screen asks for your model key. The "How will you use Delorun?" question and the review screen are gone.
- Setup picks the studio port itself: it takes 3080, or the next free port and says so. How much Delorun asks, running in the background, the profile name and phone access are in Settings → General → How Delorun runs, each with the `delorun setup` command that changes it.
- The first start runs in the terminal; Ctrl+C stops it, and `delorun start --background` keeps it running after the terminal closes. Setup ends by asking whether to keep the `delorun` command.
- A run without a terminal, or with `--yes`, asks nothing and takes safe defaults. `--phone` turns on phone access, `--import-dsh` copies your DeepSeek Harness chats, and `--port <n>` sets the studio port.
- Turning phone access off in Settings signs every paired device out and keeps the paired list; each device signs in again when you turn access on. The studio port refuses the ports web browsers block and the port phone access listens on, and a prompt change tells you to restart when the profile has hot reload off.
- **Fixed:** The end of setup no longer tells someone who ran `npx delorun` that their version "is not on the npm registry" and offers a package file that does not exist; it offers `npm install -g delorun@<version>`. Setup names the phone-pairing step only when you chose remote access.
- **Fixed:** Setup's privacy note and release-check question name releases.delorun.com and GitHub for the release check when you ran Delorun from npm, instead of describing it as a launcher built for another release channel.

## Studio
- Multiview has a layout picker with a small picture of each layout: Auto, Main and stack, Side by side, Stacked rows, Grid, Main on top, Spiral, Centred main, Activity mosaic and Tabs. Auto is the new default: up to three panes side by side, then rows on a tall window, a centred main chat on a very wide one and the main chat beside a stack of agents otherwise. A pane that would be smaller than the least pane size becomes a tab of its neighbour instead of being hidden, and Auto never rearranges while you drag or type.
- Main and stack puts the main chat on the left or the right, stacks the agents as rows, columns, a grid or a spiral, and remembers the main chat's share when you drag the divider. Activity mosaic gives working agents the large places and finished ones small places, with a short glide that reduced motion turns off.
- Arranging the panes yourself saves the arrangement as Yours, which the next Multiview uses with its own agents; a message offers Undo, and Reset to Auto clears it. An approved phone or tablet saves it too, without an unlock; if a save is refused, the message says the arrangement stays with that chat. Choosing a layout in the picker also makes it your default. Settings, Multiview, a new page, chooses whether your arrangement is remembered for the whole studio, one workspace or one chat, whether resizing panes saves it or only moving them does, and holds the other Multiview settings, including the space between panes, from edge to edge up to 32 pixels.
- New keyboard commands, with no keys until you give them some, choose the next or previous layout, move focus between panes, swap a pane with the main chat, and grow or shrink the main chat.
- The setup guide's plugin cards and the downloads panel show a download's speed and, once its size is known, the time left, measured the same way as the terminal's install display. A download that stands still shows no speed.
- The docs sidebar groups pages for people using Delorun and people building on it; old page addresses redirect.
- The docs sidebar and phone drawer end in one compact row: the language picker and a theme button that names the current theme. The site is now called Delorun Docs.
- Multiview is an icon at the end of the "N subagents" button in the chat header instead of a Multiview button with a count and a chevron. The icon has its own drawing (a main pane and two small ones) and stays lit while Multiview shows. The layouts sit at the bottom of the agents list, and right-clicking or holding the icon opens the same choice. The first time Multiview opens, a short note by the icon says where to find them, once. A keyboard command, "Multiview: show the main chat only / show Multiview", switches to the main chat alone and back, keeping the pins and the layout. It has no shortcut until you set one in the keyboard settings.
- With the Delorun look, the sidebar and side panel toggles have different icons (list lines for the sidebar, a shaded right-hand column for the side panel) instead of the same panel icon; the stock look keeps upstream's.
- Alerts, toasts, banners and dialogs share one quiet look: a translucent card with a fine edge and a soft shadow, a small status icon, a title with one muted line and a tinted action button. They slide in gently and leave quickly, hold still when the system asks for reduced motion, and turn opaque when it asks for reduced transparency. The stock look keeps DeepSeek Harness's own styles.
- When the studio loses its connection, the reconnecting card counts down to the next attempt ("Trying again in 4 s"), says when this device is offline, and keeps Reconnect now as its action.

## Chats and workspaces
- **Fixed:** Importing DeepSeek Harness chats no longer prints a MaxListenersExceededWarning for large chat logs.

## Safety and privacy
- The shield at the foot of the sidebar opens a Security panel: five rows say what the agent can do, whether you can undo a change, who can reach the studio, what you added and whether this copy of Delorun is genuine, each green, amber or red with the reason, whether it is your choice, and one button that fixes it. When everything is green it shows one line, "Protected as Delorun intends"; Advanced breaks every row down and is remembered.
- Shortly after Delorun starts, once no chat has been busy for a moment, it hashes every installed file through the launcher at low priority and stops if a chat starts working, so this copy reads "Verified" without pressing Check now. It reads plugins and your changes again after a plugin is added, updated, switched or removed, and each check shows how long ago it ran.
- The privacy page names the publisher, the footer reads "Published by Delorun", and the licence files and the SBOM name Delorun instead of "Delo Run"; the first-run notice no longer names a maintainer.

## Reach
- A device that asks to pair opens a pop-up at your computer by default: the device's details and the time left, the box for the 8-digit code with Submit, and **Not you making this request?** to decline it. **Don't show this pop-up again** switches back to the quiet notice, and Settings → Devices offers the pop-up, the notice or nothing.
