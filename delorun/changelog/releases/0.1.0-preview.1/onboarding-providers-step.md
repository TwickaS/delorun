- Setup has a Models step right after Welcome. It lists the providers you can connect with a key, ticks the ones whose key it already found, walks you through each ticked provider (paste the key, see it tested, then Next or Skip) and ends with a summary. Each provider links to its own key page, and a pasted key is tested with the provider's free model list, which shows how many models it offers and the default one. Keys are write-only: Delorun shows "Key found" or "Key saved", never the key.
