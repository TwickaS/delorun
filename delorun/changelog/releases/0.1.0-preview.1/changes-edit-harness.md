- `delorun changes edit-harness` makes your own copy of the installed Delorun's program files and prints its folder. Each file you save, add or delete there is a change to Delorun itself, listed in `delorun changes list`. With protection off, the default, the next `delorun start` applies it without review, says so, and `undo` takes it back; with protection on it waits for your review, and `show`, `apply`, `discard` and `undo` decide it as they decide a plugin's change, at a terminal. An applied change runs from Delorun's next start, beside the installed release, which is never edited and is checked at every start as before; `delorun changes edit-harness --discard` takes every change to Delorun itself back, even from a copy Delorun can no longer read, and the next start runs the installed release unchanged. A release too large for Delorun to read your copy of is refused before anything is copied. When Delorun fails to start right after such a change, including when a changed file stops Delorun before it starts, it starts once more without it and names it; when it does not start without it either, it names `delorun changes undo <id>` and `delorun changes edit-harness --discard`. Safe mode runs the installed release without any of your changes to it. `delorun verify` and `delorun doctor` list the files you changed and never report a pass when the files Delorun would run with your changes differ from what you applied.
