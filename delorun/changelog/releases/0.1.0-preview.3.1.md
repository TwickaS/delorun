# Delorun 0.1.0-preview.3.1

## Install and update
- **Fixed:** `yarn add delorun` and `yarn dlx delorun` now install and start Delorun with Yarn 4's default Plug'n'Play, as `npx` does. They stopped with `TRUST_STATE_INVALID: the trust file cannot be written`. The launcher starts one plain Node process for itself under Plug'n'Play, and its package asks Yarn to unpack it. If Yarn keeps the package in a zip, the launcher says so in one line and names `nodeLinker: node-modules` and `npx delorun`.

## Safety and privacy
- With Ask me first, Delorun asks before starting an MCP server that comes from a plugin, a bundle someone else made, your editor or a place it could not identify. Servers you set up yourself and servers Delorun's packs install start without asking; a bundle that only carries a pack's name is not a pack, and an allowance given before this version asks once more for servers from plugins and editors. Settings, Safety, Permissions chooses which servers ask: Ask for project servers (the default), Always ask or Never ask; the choice changes only at your computer. A waiting server shows as a small card above the message box with Allow, Not now and Details, and an allowed server starts at once, with its tools in the open chat's next message.
