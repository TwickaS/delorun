# Delorun 0.1.0-preview.1.15

## Studio
- The agent cards for Claude Code and Codex show whether the agent is signed in and on which plan, with a bar for each plan limit and its reset time on your own clock. The same bars are in Settings, Safety, External agents, under Plans and limits, and in a Plans pill beside the cost pill that shows your highest used share. Delorun reads the figures only when you press Check now, add an agent or finish signing in.
- A live agent's chat, behind the `externalAgents.liveAgents` preview flag, opens with a coloured rule and a card that says the agent runs outside Delorun, with its program, own settings, sandbox state and plan limits. Its commands, searches and edits show as cards, its questions as one approval card with Reject, Allow for this run and Allow once, and its start, plan limit, sign-in and model choice as plain notices.
- The model picker in the composer looks calmer: roomier rows with 44px tap targets on touch screens, a clearer selected model, quieter provider headings, and a menu that fills the width of a phone screen.
- The picker's search field is larger on phones, with a search icon and 16px text so the page does not zoom, and the menu drops its wide glow for a plain shadow.
- **Fixed:** In Settings → Appearance, choosing a theme tile after Custom now shows that theme. In 0.1.0-preview.1.6 the Soft tile after a custom accent, or any theme tile after a changed contrast, left the studio in Custom; the theme now also puts back Peach for Soft and the default contrast.
- **Fixed:** Codex's weekly plan limit is called "Weekly limit", as Claude Code's is, instead of "7-day limit".
- **Fixed:** A busy computer, or Docker Desktop starting and stopping containers under WSL, no longer makes Delorun think it has no sandbox. When the sandbox's start-up check times out or the computer is briefly out of memory or processes, Delorun checks again a few times without freezing, never remembers a failure beyond the command that met it, and says plainly that the fault is temporary: retry, or use a tool that needs no shell, such as web search. A sandbox that fails to start because a mount point vanished is repeated once with a fresh mount list, and Docker Desktop's changing mount folders are left out of the sandbox's view. A lasting cause, such as a blocked user namespace, still gets the install advice.
- **Fixed:** If the agent then asks to run without the sandbox, the approval card shows "Delorun's sandbox had a problem; this asks to run without it" as its own line, offers no "allow for this chat" choice, and declining tells the agent to retry inside the sandbox. The note clears after the next sandboxed command runs. A command is still never run unconfined because of a failed check.
- **Fixed:** Commands run inside a chat's sandbox no longer refuse Delorun's home as "mode 0755" when the real folder is private. Only Delorun's own sandbox launcher marks that view as untrustworthy; anywhere else a 0755 home is still refused.
- **Fixed:** Delorun's own start, setup and update commands always check that its home is private, even from inside a chat's sandbox.
- **Fixed:** When no sandbox can start on a computer at all, the message now speaks to the person who runs Delorun and tells the agent not to ask for full access because of it; it only reports that the sandbox is unavailable.
- **Fixed:** Bold text in the studio is drawn in Schibsted Grotesk's and JetBrains Mono's real heavier weights. Both typefaces are variable fonts, but their declared weight range stopped at medium, so the browser thickened the medium face for semibold and bold text; the declared ranges now match the files (Schibsted Grotesk 400 to 900, JetBrains Mono 400 to 800).
- **Fixed:** In Settings → Appearance on a very narrow phone (under 380 px wide), the theme tiles set their names smaller and let them wrap, so a name such as "Custom" is read whole instead of being cut to "Cust…". The colour of the name is unchanged and keeps at least 4.5:1 against the tile in every theme.

## Chats and workspaces
- The model now knows it is working in Delorun and which model is answering, and mentions DeepSeek Harness only when you ask how Delorun is built. On an installed copy it no longer receives the program folder or the studio address, and creator chats point to the plugin-authoring skill and the Changes page. Guidance for terminals, workflows and delegation is sent only when those tools are on offer, the file-link rules are shorter, and the time note no longer says the elapsed time is unavailable.

## Safety and privacy
- When your Claude or ChatGPT plan's limit is reached, Delorun does not start Claude Code or Codex for a chat until the limit resets. The chat is told which limit is reached and when it resets, so it does the task itself or tells you instead. Figures whose reset time has passed never stop a start.
- **Fixed:** When Browser's output folder would sit inside a folder the chat can write, for example when the workspace is your home folder, a new chat starts normally with Browser's tools off, instead of every new chat failing. The reason is written to Delorun's log, and its advice depends on the cause: the workspace, an extra writable folder, or `XDG_CACHE_HOME`. Browser still never writes to a folder the chat's sandbox can write, and it stays off whenever the file system cannot resolve the folders to check. Any other error in that check still fails the chat's creation.

## Reach
- A paired phone or second computer needs no unlock to turn protection on, cancel or dismiss an update, run a trust check, list an agent's models, read a clone's progress or a workspace's defaults, or turn the real-browser away permission off, because each of those only reads or tightens.

## Plugins
- The Plugins screen now shows a title and a sentence for the plugins that guard your consent, fetches and sign-in (such as Fetch guard, Instruction consent, Reach and Device sign-in), where it showed only their package names.

## Commands
- `delorun agents status` shows whether Claude Code and Codex are signed in, your plan, and how much of each plan limit is used, with when it resets and when Delorun last saw the figures. Without a running Delorun it shows the figures last seen. `--refresh` asks the running Delorun to check now, which starts the agent's own program with no task; `--json` prints the figures for scripts.
- **Fixed:** `delorun agents login claude-code` finds the Claude Code that the agent's plugin brings, instead of saying it is not added. After a sign-in, a running Delorun checks that agent's plan limits.
