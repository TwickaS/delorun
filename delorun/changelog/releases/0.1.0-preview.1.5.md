# Delorun 0.1.0-preview.1.5

## Setup
- The setup guide's recommended plugins include Computer use (Cua Driver), marked experimental: it lets an agent see and control the windows on the desktop on Linux and Windows. It stays off until you add it, and it asks for the desktop permissions it needs.

## Plugins
- **Fixed:** The Agents step no longer keeps showing "Adding…" under a failed download. The card follows the Host's install list for as long as it shows an install, including after the step re-reads its cards, and ends with the reason when the install fails.
- **Fixed:** Adding Claude Code or Codex no longer fails while unpacking with "tar header uid is not an octal number". The reader now accepts the tar headers that `npm publish` writes (empty owner fields, space-padded numbers). It still checks each file's size, mode, type and path, and applies no owner or time from the archive.
- **Fixed:** A plugin pack that installed but whose plugins did not load no longer shows as plain "installed" on the Plugins page. The card says "Installed, but not loading" with the reason, and offers Try again and Remove, which uninstalls it.
- **Fixed:** The Agent hooks pack's Claude Code and Codex hooks now load once added; in 0.1.0-preview.1.4 they installed but failed to load with "Cannot find package". Each optional pack now carries or links every package its plugins use, and a release is no longer built when a pack would miss one.
