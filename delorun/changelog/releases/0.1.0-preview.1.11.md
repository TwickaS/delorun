# Delorun 0.1.0-preview.1.11

## Install and update
- **Fixed:** Delorun starts again after the computer restarts, or after a Windows Subsystem for Linux distro restarts while its virtual machine keeps running. A lock left behind by the run before no longer stops the next start.

## Safety and privacy
- A chat in the Standard or Creator preset lists your plugins and bundles without asking for approval. Every change to them, such as installing, removing or turning one on or off, still asks.
- **Fixed:** Browser now saves screenshots, downloads and PDFs in a folder Delorun creates for each chat in your cache folder, outside the chat's folder, so a command running in the chat's sandbox can read a saved file but cannot replace the folder or point it somewhere else. Browser only writes there, and a file it uploads from the chat's folder is copied by Delorun first, so a link swapped in at the last moment cannot make Browser read a file the chat could not. Browser also checks each file after it lands; one that ends up outside the chat's folder or the output folder is removed when Delorun can do so safely, and the result is refused with a message. A chat with Full access runs outside the sandbox, so for it this is a refusal, not a barrier.
