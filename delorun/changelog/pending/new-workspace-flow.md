- A new workspace can be an existing folder, a new folder with a Git repository started for it, or a clone from Git on a branch you name. Folder search, recent and suggested folders and a preview of each folder help you find the right one.
- Each workspace can have its own model and thinking level, which every new chat there starts with.
- Delorun never makes or adds a workspace in your home folder itself, in its own home or in system folders, or outside the folders it is set to use, even through a link.
