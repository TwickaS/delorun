section: Added

- Phones confirm sensitive actions with Face ID, or with the device lock where there is no Face ID, and set it up when pairing or in Settings, Devices. It is on for every home, with no preview switch to turn on; a home that had set the old `unlock.passkeys` preview switch keeps its other preview switches, and the retired one is ignored with a line in the log. A phone with no passkey confirms with its PIN. Phone powers is gone, so there is no level to choose.
