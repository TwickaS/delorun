- `delorun agents status` shows whether Claude Code and Codex are signed in, your plan, and how much of each plan limit is used, with when it resets and when Delorun last saw the figures. Without a running Delorun it shows the figures last seen. `--refresh` asks the running Delorun to check now, which starts the agent's own program with no task; `--json` prints the figures for scripts.
