- The "Choose a folder" step of New workspace uses the whole dialog. One row holds clickable breadcrumbs from Home, the folder search and a New folder icon button. The folders fill the width until you select one; then a summary of it opens beside them: its name and path, the stack its project files show (Node.js, Python, Rust and others), its Git branch and latest commit, its top-level files with their sizes, and a Use this folder button. On a phone the folders fill the screen, and the summary opens as its own full-screen step with a Back button.
