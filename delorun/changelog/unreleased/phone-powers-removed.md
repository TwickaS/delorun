---
area: Safety and privacy
section: Removed
---

- Phone powers, with its Careful and Full levels, is gone. A phone no longer has a level to choose: each action that changes what Delorun runs, such as opening a terminal, applying a change, turning protection off, making your copy of Delorun, restarting it and updating it, asks for Face ID, or for your PIN on a phone with no Face ID, each time it is taken. A phone without Face ID can now do these strong actions, and installs, full access, network settings, MCP server and external agent answers, the folder picker, new workspaces, settings changes, saving or removing a model key and approval answers too, by typing its PIN once for each action: the PIN confirms that one action and opens no window, so the next action asks again, where Careful refused them before. A phone with Face ID confirms each one with Face ID. No PIN unlock, code from your computer, approval grace or Never ask mode opens any of them, so a phone that was unlocked before still asks, and a refused action no longer asks for a code from your computer. Typing your PIN no longer unlocks a phone's page for a while: the PIN lock screen is gone, every phone is refused a PIN unlock, and a phone with no Face ID reaches exactly what a phone with Face ID reaches. A phone's Settings, Devices no longer offers Unlock, Show the code or Lock now, PIN mode drops its idle time and lock-when-hidden choices, and on a phone the first-run guide says model keys are tested at your computer instead of offering a Try again that always fails. `delorun devices powers` and `delorun setup --phone-powers` no longer exist, setup stops asking what an unlocked phone may do, the Settings, Devices choice is removed, and the `phonePowersOnUpgrade` setting of the device sign-in plugin and the `/auth/phone-powers` address are gone. An answers file that still holds `phonePowers` loads, and the answer is ignored with a line saying so.
