- Closing Multiview with its button now keeps it closed. A chat that hands work to a new agent no longer reopens Multiview after you have closed it; the new agent is still pinned, and the icon shows its count and its amber dot. Opening Multiview again, from the icon, the agents list or the keyboard command, lets the next hand-off open it as before. The setting that opens Multiview on every hand-off still turns that off entirely, and turning it on no longer overrides a close you made.
