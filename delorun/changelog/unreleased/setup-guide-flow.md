- The setup guide keeps your current workspace when you skip the Workspace step after running setup again, and Continue adds the folder you highlighted.
- Escape works as Finish later, and a "Finish setup" chip above the message box brings the guide back at the step you left, even before your first chat exists. Ready does not offer Finish later.
- Recommended plugins show placeholder rows until their titles arrive, and Agents asks "Add Claude Code first?" when you press Continue with an Add question open.
- Phone access shows its command in a code box with "Not now" in place of Skip, and "I've done this" continues once you have run the command. Ready says whether phone access is on, not set up, or worth checking in Settings → Devices, and names the colour mode; the Look preview stays in view while you choose.
- Skip on Workspace keeps your workspace when you have one and uses the default when you have none.
