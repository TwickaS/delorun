area: Chats and workspaces
section: Changed
---

- A subagent can run on any provider and model you have configured, including a different provider from the agent that started it, at any depth. Reasoning effort follows the chosen model unless the agent names one. The Subagent settings page keeps its model list, which now narrows that choice: tick nothing and every configured model is available. The switch that lets agents choose at all is on by default, so a subagent pointed at an expensive model spends real money and the model appears only in the tool call.
