- Setup's last step no longer tells you to install a version from npm that npm does not have. A launcher built for a local release channel says to install the package file it came from, and the release-check note names that channel's host instead of releases.delorun.com and GitHub.

- Settings → General → Updates, and the dialog that asks before the release check turns on, name the host this installation actually contacts when its launcher was built for another release channel. The production wording is unchanged.
