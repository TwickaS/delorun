- With Ask me first, Delorun asks before starting an MCP server that comes from a plugin, your editor or a place it could not identify. Servers you set up yourself and servers Delorun's packs install start without asking. Settings, Safety, Permissions chooses which servers ask: Ask for project servers (the default), Always ask or Never ask; the choice changes only at your computer. A waiting server shows as a small card above the message box with Allow, Not now and Details, and an allowed server starts at once, with its tools in the open chat's next message.
