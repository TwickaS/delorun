# Unreleased changes

English | [中文](README.zh.md)

The fragments for what exists and works now and is not yet in an assembled version live in this folder, one file per thing a person can perceive.
A later change to the same thing edits its fragment; the front matter, the areas and the commands are described in [the changelog README](../README.md).
Run `node_modules/.bin/tsx delorun/apps/release/src/changelog/assemble.ts --list-unreleased` to see where a change belongs.
