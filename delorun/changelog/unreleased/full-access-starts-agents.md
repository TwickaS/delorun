- A chat on Full access now starts Claude Code and Codex without asking, because you already chose to run that chat without prompts, and the chat shows "Started without asking · Full access" under the hand-off. Before, it refused and told you to allow the agent for the workspace. Read Only chats, chats without a workspace folder and run folders outside the workspace still refuse, and an Ask chat still asks. To make Full access chats ask again, turn off **Full access chats start agents without asking** in Settings, Safety, External agents; only your computer turns it back on, a phone can turn it off.
