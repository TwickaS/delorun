- After an update, the outcome card shows up to five one-line highlights from the release notes of every version the update skipped, with a Read more button that opens the full change log of those versions in a sheet (full screen on a phone). It reads the notes the update shipped, so it works offline. The card keeps each version number on one line and shows the finish time in your own time zone.
