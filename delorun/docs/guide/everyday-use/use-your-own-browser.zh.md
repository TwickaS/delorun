# 使用你自己的浏览器

[English](use-your-own-browser.md) | 中文

> 英文页面是当前版本；本页可能落后于它。

## 摘要

本页介绍如何让智能体在你已登录的 Chrome 中，完成一项你正在看着的任务。当任务需要用到你的账号时，它会有帮助，例如在你常用的网站上填写表单，或阅读你自己的仪表盘。你需要让 Delorun 运行起来，并在同一台电脑上安装 Chrome（或其他基于 Chromium 的浏览器，如 Edge 或 Brave）。智能体通过 [browse](https://github.com/anomalyco/browse) 在你的浏览器中操作，它是 Anomaly 出品的开源扩展和辅助程序。Delorun 自带一份 browse，所以除了扩展之外你无需自己安装任何东西。

你自己的浏览器永远不会被擅自使用。智能体会先在 [chat](../../reference/glossary.zh.md#chat) 中询问，只有你允许的 chat 才能使用它。**浏览器** 插件包的隔离浏览器保持不变：除非你在“设置”的 **浏览器** 下将它关闭，否则它是开启的，第一次使用时 Delorun 会添加该插件包并下载它的浏览器部分，这可能需要几分钟。如果已安装 Chrome，Delorun 会先使用它；否则会下载它自己的 Chromium。**设置 → 浏览器** 会显示进度；如果下载无法完成（没有连接、插件包被拒绝或找不到 Chrome），则会说明该怎么做，并带有 **重试**。

## 添加并配对 Chrome

1. 在侧边栏打开“插件”，找到 **你自己的浏览器**，选择 **添加**。Delorun 会下载插件包并检查它的签名。
2. 开启它的浏览器行。Delorun 会请你接受一次 browse 的程序，因为它在 chat 的沙箱之外运行；一次接受即可覆盖所有 chat。
3. 在 Chrome 配对之前，该行显示“需要设置 · 需要连接 Chrome”。按照它下方的步骤操作：
   1. 选择 **打开 Chrome 应用店**，把 browse 扩展添加到 Chrome。
   2. 选择 **获取配对码**。Delorun 会显示一个配对码，例如 `AB12-CD34`。
   3. 在 Chrome 中打开 **扩展程序 → browse → 选项**，选择 **用配对码配对**，输入配对码并选择 **连接**。

你应该会看到该行变为就绪。配对码只能使用一次，有效期十分钟。你只需配对一次；重启 Chrome 或 Delorun 后，Chrome 仍保持配对。

配对只能在电脑本机上完成。已配对的手机可以看到该行，但不能获取配对码。

<a id="allow-it-in-a-chat"></a>

## 在 chat 中允许它

当任务需要你的浏览器时，智能体会请求使用它。chat 中会出现一张审批卡片，写明智能体想用它完成的任务，并说明智能体将使用你自己的浏览器和你的登录状态。允许它，或拒绝以将它排除在外。

你可以在电脑上允许，也可以在已解锁的手机上允许：即你已配对、并为这次回答解锁的手机。不久前为其他事情解锁不算数，只是登录了的手机也不能允许它。“你不在时”的许可同样如此。

一旦允许，它会一直有效，直到你关闭它或 chat 结束，Delorun 重启后也依然有效。该 chat 中不是由你发起的运行，例如定时运行，只有在你也允许了“你不在时”使用的情况下才能使用它；这项许可持续七天（除非该行的设置另有规定），你可以再次授予。没有人能应答的运行，例如 `delorun headless`，不能使用它，并会说明这一点。

<a id="what-the-agent-can-do-there"></a>

## 智能体在那里能做什么

智能体会在你的浏览器中打开它自己的标签页，并用简短的脚本在其中工作：阅读页面、点击、输入，并收集任务所需的内容。完成后它会关闭自己打开的标签页。它不会动你打开的标签页。

遇到登录、验证码、付款或任何只应由你来做的事，智能体会把这一步交还给你。页面上会出现一条消息；请你亲自完成这一步，然后在页面上选择 **继续**。只有你自己的点击才能让智能体继续。

智能体只在你允许的任务中使用你的浏览器。其他的网页阅读，它会继续使用隔离浏览器，那里没有任何登录状态。

<details>
<summary>边界情况</summary>

- 如果该行显示“Windows on Arm 不支持”，说明 browse 没有适用于你电脑的程序。隔离的 **浏览器** 插件包仍然可用。
- 如果配对码在你输入前已过期，请选择 **获取新配对码** 并输入新的配对码。
- 如果 Chrome 已关闭，或扩展被关闭，智能体会告诉你它无法连接到你的浏览器。打开 Chrome 后再请求一次。
- 如果你已经在其他智能体中使用 browse，Delorun 会共用同一个到 Chrome 的连接。当正在运行的 browse 与 Delorun 的版本不同时，审批卡片会说明这一点。
- 如果 Chrome 更新了扩展，而它不再与 Delorun 的 browse 兼容，智能体会说明 browse 需要更新。更新的 Delorun 发行版会带来新的 browse。
- 如果你在 WSL 中使用 Delorun，而 Chrome 在 Windows 上，Delorun 会在 Chrome 旁边运行它自带的 Windows 版 browse。
- 如果智能体在你不希望的 chat 中请求你的浏览器，请在卡片上拒绝。该 chat 中不会有任何变化，智能体会继续使用隔离浏览器。

</details>

<details>
<summary>进一步了解</summary>

智能体的脚本在它打开的页面中运行，所以它们能读取这些页面显示的任何内容，并以你的身份从这些页面发出请求，就像页面上的任何脚本一样。智能体读到的网页、邮件或文档可能会试图给它下指令。智能体被告知要忽略这些指令，并在做任何难以撤销的事情之前先问你，但你才是最后一道检查：只在你看着的任务中允许你的浏览器，其余情况请拒绝。

browse 还有自己的限制：它不允许脚本清除你的 cookie、打开浏览器的内部页面，或读取其他网站存储的数据。这些限制能让错误的影响保持很小；它们并不能挡住一个想要你数据的页面。

Delorun 自带的 browse 从不自行更新，Delorun 启动它时会关闭 browse 的额外访问开关。要移除配对，请在 Chrome 中打开扩展的选项，并在那里移除连接。

</details>

<a id="turn-it-off"></a>

## 关闭它

要在某个 chat 中结束它，请在该 chat 中关闭它；智能体会立即停止使用你的浏览器。要在所有地方停止它，请在“插件”中关闭 **你自己的浏览器**。在你从扩展中移除配对之前，Chrome 会保持配对。
