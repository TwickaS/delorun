# 逐字阅读模型的思考过程

[English](thinking-tab.md) | 中文

> 英文页面是当前版本；本页可能落后于它。

## 摘要

本页介绍如何在右侧边栏中，在模型书写的同时，一次一个词地阅读模型的推理和回复。如果你想跟着读而不必滚动一段很长的回答，它会有帮助。你需要先让 Delorun 带着一家模型提供方运行起来（见[模型提供方](../get-started/providers.zh.md)）。这个标签页在你开启之前是关闭的，并且它自己不发出任何请求：它显示的是模型已经发送到 [chat](../../reference/glossary.zh.md#chat) 的内容。

<a id="turn-it-on"></a>

## 开启它

在侧边栏打开“插件”，然后打开 **Delorun studio**。在 Components 下找到 **Thinking tab** 并开启；它会立即启动，无需重启。然后打开右侧边栏并选择 **Thinking**。这个标签页会跟随你所在 chat 的最新一轮。

新手引导的“推荐插件”步骤提供同样的开关。

<a id="the-band-and-the-page"></a>

## 色带与页面

色带在固定的位置一次显示一个词，并标出你的视线应当落在的那个字母。以句子或分句结尾的词会多停留一小会儿。

色带下方的页面列出每一个词。你已经读过的在色带上方，还没读到的在色带下方，每一部分都标有“推理”或“回复”。向任一侧滚动即可回看或前看；色带保持在原位。

<a id="choose-what-and-how-fast"></a>

## 选择读什么、读多快

- **Read** 选择推理、回复，或按模型书写的顺序同时显示两者。
- **Pace** 选择色带如何移动：**Live** 在模型写出每个词时就显示它，**Set rate** 以每分钟 100 到 1,000 个词的速度播放，**Model's rate** 则跟随模型书写的速度。
- **Delay** 让每个词在写出之后最多推迟 30 秒再显示，这样你读到的是落后于模型的平稳文字流。它适用于设定速度和模型速度。
- 控制按钮可以播放和暂停、向后或向前退一个词、重新开始，以及跳到最新的词。

你的选择保存在这个浏览器中。

<details>
<summary>边界情况</summary>

- 如果你的系统要求减少动态效果，那么标签页会以暂停状态开始。
- 如果文本是中文或日文这类词与词之间没有空格的文字，那么标签页仍然会逐词阅读。
- 如果 chat 还没有任何推理或回复，那么标签页会说明没有可读的内容。
- 如果你在“设置”中切换为 stock 外观，那么标签页会消失。重新开启 Delorun 外观即可再次看到它。
- 如果你关闭该插件，那么标签页会消失，而你的 chat 保留其历史记录。

</details>
