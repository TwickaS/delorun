# Delorun defensive patterns

English | [中文](README.zh.md)

Delorun's defensive patterns state rules that review enforces in Delorun's code, each with the defect it prevents. Upstream's [defensive patterns](../../../docs/defensive-patterns/README.md) apply to Delorun as well, and Delorun's pages extend them. Delorun has no patterns of its own yet.
