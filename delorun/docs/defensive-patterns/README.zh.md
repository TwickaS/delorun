# Delorun 防御性模式

[English](README.md) | 中文

> 英文页面是当前版本；本页可能落后于它。

Delorun 的防御性模式陈述评审在 Delorun 代码中执行的规则，并说明每条规则所防止的缺陷。上游的[防御性模式](../../../docs/defensive-patterns/README.zh.md)同样适用于 Delorun，Delorun 的页面对其加以扩展。目前尚无 Delorun 自己的模式。
