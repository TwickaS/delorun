# 差异索引

[English](README.md) | 中文

> 英文页面是当前版本；本页可能落后于它。

Delorun 修改了上游 DeepSeek Harness 的一些文件。差异台账记录其中每个文件，使与上游的差异可测量、可审查。本页定义台账、其条目和路径规则，如何阅读、写入和测量它，以及限制它在一次发布内可增长多远的差异预算。

## 台账

台账是 [`delorun/upstream-patches.json`](../../../../upstream-patches.json)，其 [schema](../../../../upstream-patches.schema.json) 描述其结构。Delorun 自有目录之外、与其所固定的上游提交存在差异的每个文件，要么是 `patches` 之下的一条条目，要么被 `rules` 之下的路径规则涵盖。Delorun 自有的目录为 `delorun/`、`.agents/skills/delorun-*/` 技能与 `.agents/notes/**/*-delorun-*` 笔记。这些文件属于 Delorun，而不是上游修改，因此台账不记录它们。

一条条目指名一个上游文件，附上其类别和修改原因，不论它有多少差异块。每个存在差异的上游源文件都是一条条目，每个其修改移动了某个闸门的文件也是。路径规则以一条原因涵盖一组不是上游源码的文件，例如规格、翻译和文档。上游吸收某项修改时，其条目移入 `retired`，记录吸收它的上游提交及其所含的差异块。退役条目保留在台账中，并在[差异预算](#divergence-budget)中被抵扣。

当一个路径位于 `packages/` 或 `apps/` 的 `src/` 目录之下、位于 `native/` 之下、是 `python/` 之下的 Python 文件，或是 `scripts/tests/` 之外的 `scripts/` 之下的 `.ts` 或 `.mjs` 文件，并且它不是规格或测试文件（`*.spec.*`、`*.test.*`），不在 `tests/`、`__tests__/`、`fixtures/` 或 `snapshots/` 目录之下，不是 Markdown，也不是 `.i18n.yaml` 一致性记录时，它就是上游源码。`vendor/` 之下的每个路径都是上游源码。存在差异的源文件需要一条条目；没有路径规则涵盖它，只是精确的 `generated` 规则可以指名 `vendor/` 之外的生成源文件。

每条路径规则有 `pattern`、`kind` 和 `reason`。`pattern` 是针对仓库相对路径的 glob，由 Node 的 `path.posix.matchesGlob` 完整且区分大小写地匹配：`*` 在一个路径段内匹配，`**` 跨段匹配，二者都不匹配以 `.` 开头的段，因此针对 `.github/` 或 `.agents/` 的规则要写明该目录。`kind` 有 `tests`、`recorded-sessions`、`translations`、`documentation`、`tooling` 和 `generated`。

检查会拒绝会涵盖源码的规则：单独的 `**`，以及其 pattern 匹配树中某个源路径或检查自身源码探针之一的任何规则，拒绝信息写明该 pattern 和一个这样的路径。作为规格、位于测试、夹具或录制会话树中、或是 Markdown 或一致性记录的 `vendor/` 路径，不会使规则成为错误，因为没有规则涵盖 `vendor/` 路径。指名源文件的 `generated` 规则必须精确地指名它，并且该文件的前五行必须含有 `Generated by scripts/`。

规则不需要检查其路径是否仍有差异。边界检查会打印每条规则涵盖多少存在差异的路径，并对不涵盖任何路径的规则给出警告。

写入条目和摘要的是工具，而不是人或智能体。`node_modules/.bin/tsx delorun/apps/tools/src/ledger-record.ts` 将工作树与所固定的提交比较。它为既没有条目也没有规则涵盖的每个存在差异的路径添加一条存根条目，其功能和原因为 `TODO`；移除其路径已不再存在差异的每条条目；并重新记录文件已更改的每条 security 条目的摘要，逐条打印。在 lead 写下类别、功能和原因之前，检查拒绝 `TODO` 值。重新记录了摘要会使该命令以 3 退出，因为更改过的 security 文件需要 lead 重新审查。`--check` 不改变任何内容，并在该命令会改变台账时以 1 退出；智能体只运行 `--check`。路径规则由 lead 编写。

## 类别

| 类别 | 含义 |
| --- | --- |
| `delorun-feature` | 该修改服务于 Delorun 的某项功能。 |
| `generic-fix` | 该修改是上游可以采纳的修复。每项通用修复单独成一次提交。 |
| `security` | 该修改改变了批准、拒绝或权限提升。它附有 lead 的结论，以及在修改前失败、修改后通过的拒绝测试。 |

其修改移动了某个闸门的文件是一条 `security` 条目，无论它是源码、规格还是页面；没有路径规则取代 security 条目，同时匹配它的路径规则仍让它保持为条目。`security` 条目记录 `sha256`，即其文件的 SHA-256 摘要，它把 lead 的结论绑定到所审查的内容；它不写明任何功能。只有 `security` 条目可以列出 `nonModelVisibleHunks`，即 lead 审查为对模型不可见的差异块的摘要，这些差异块位于注册对模型可见的贡献的语句之内，由 `ledger-record.ts --non-model-visible-hunk` 写入，[`parity-switches` 检查](../../../../apps/tools/README.zh.md#what-parity-switches-detects)每条记录放行一个差异块。`delorun-feature` 或 `generic-fix` 条目写明它所服务的 `feature`，不记录摘要。同时被路径规则涵盖的非 security 条目，会因既被列出又被规则涵盖而被拒绝。

<a id="reading-the-ledger"></a>

## 阅读台账

- `upstream.repository`、`upstream.ref` 与 `upstream.commit` 固定了每条条目所据以测量的上游提交。上游版本合并时，固定的提交随之变化。
- `forkOwned` 列出 Delorun 完全自有的路径与 glob。
- `rules` 列出路径规则，每条带有其 pattern、kind 和 reason。
- `patches` 列出每条条目，附其类别、其功能或摘要，以及说明修改内容与原因的 reason。
- `retired` 列出上游已吸收的条目，附吸收提交与每条所含的差异块数。

<a id="measuring-the-ledger"></a>

## 测量台账

`pnpm --filter @delorun/tools check` 运行台账检查，任何违规都以 1 退出。检查针对固定提交与工作树执行。其拒绝的完整情形列在 [tools 说明](../../../../apps/tools/README.zh.md)中。

`node_modules/.bin/tsx delorun/apps/tools/src/check-fork-boundary.ts --count` 运行相同的检查，并打印差异：列出的条目数及其差异块数，以及被规则涵盖的路径数及其差异块数。差异块是相对固定提交的 `git diff --unified=0` 中的一个 `@@` 头；未跟踪的文件计为一个差异块。退役条目单独列出，不计入数量。

<a id="divergence-budget"></a>

## 差异预算

预算限制台账在一次发布内可增长的幅度，并列出执行该限制的检查。

- **数量。** 一次发布的数量是台账中按类别计的条目与差异块，以及作为类别 `ruled` 的、被规则涵盖的路径与差异块；生成的路径计入 `ruled`。退役条目对数量进行抵扣：增长按扣除退役条目所记录的条目与差异块后的净值计算。
- **增长上限。** 每次发布的增长上限为 20 条与发布 0.1.0 基线条目数的 10 % 中较大者。差异块的增长上限为 150 块与发布 0.1.0 基线差异块数的 10 % 中较大者。
- **超出。** 超出任一上限，需要维护者的决定，并记录于发布说明中。
- **预演合并。** Delorun 的预算要求：将树预演合并到上游最新标签时，若冲突的差异块超过该标签处台账差异块数的 15 %，则预演合并失败。当任何 `security` 类文件发生冲突而未记录维护者的决定时，它也失败。`node_modules/.bin/tsx delorun/apps/tools/src/rehearse-upstream.ts --tag <tag>` 在临时工作树中运行预演合并，并同时把增长限制在上限之内；`--ref <ref>` 则预演克隆中已有的某个提交或分支，例如 `upstream/master`。[tools 说明](../../../../apps/tools/README.zh.md#the-rehearsal-merge)描述其输出。
- **基线。** 基线是发布 0.1.0 处台账的条目与差异块，记录在该发布的说明中。没有已记录的基线时，上限就是下限，即 20 条条目与 150 个差异块。
- **当前数量。** `node_modules/.bin/tsx delorun/apps/tools/src/check-fork-boundary.ts --count` 输出台账相对于基线标签的条目与差异块数量。

<a id="divergence-records"></a>

## 差异记录

对上游某一领域的重大修改，会在本目录下拥有各自的差异记录页面，说明如何为该领域合并下一个上游版本。产生该差异的修改同时添加该页面。目前尚无差异记录。

上游合并遵循根目录 [AGENTS.md](../../../../../AGENTS.md#the-fork-boundary) 中的分叉边界规则。
