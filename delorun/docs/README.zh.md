# Delo 文档

[English](README.md) | 中文

Delo 的文档按层级组织在 `delorun/docs/` 下，与上游位于 `docs/` 下的文档并列。每个事实只有一个归属，即承担其职责的层级，其他页面链接到那里。涉及上游的页面链接到上游文档，而不重复其内容。

- [指南](guide/README.zh.md)：面向 Delo 使用者的用户指南，从 [Delo 与 stock DeepSeek Harness](guide/delorun-vs-stock.zh.md) 开始。
- [实操手册](cookbook/README.zh.md)：面向任务的分步指南，每份指南以带编号的验证步骤结束。目前尚无任何指南。
- [参考资料](reference/README.zh.md)：用于查阅的页面，定义现行行为与术语，从[术语表](reference/glossary.zh.md)开始。
- [防御性模式](defensive-patterns/README.zh.md)：Delo 代码评审所执行的规则，扩展了上游的[防御性模式](../../docs/defensive-patterns/README.zh.md)。Delo 目前尚无自己的模式。
- [架构说明](architecture/README.zh.md)：Delo 各子系统的有序地图，每个子系统一页现行状态说明。目前尚无任何说明页。
