# @delorun/plugin-cost-meter

[English](README.md) | 中文

> 英文页面是当前版本；本页可能落后于它。

估算每个 chat 已花费的费用，显示在输入框下方，并把该 chat 启动的各 chat 加总在其下。默认关闭：在侧栏「插件」的 Delorun studio 页面中，于「组件」下开启。

## 显示内容

输入框下方的药丸形标签显示本 chat 的费用；一旦有子 agent 或队友产生了费用，则显示两个数字：仅本 chat，以及本 chat 加上它启动的各 agent。点击药丸打开的对话框按模型列出请求数、新 token、缓存 token 和费用，再列出输入、缓存写入、缓存读取和输出 token。新 token 是提供方重新处理的 token（输入、缓存写入和输出）；缓存 token 是它从缓存中读回的先前输入，费用低得多，chat 中有缓存 token 时对话框会说明这一点。有 agent 参与时，本人打开的每个 chat 和 agent 启动的每个 chat 各占一行，按费用从高到低排列；在 studio 之外运行的 chat，其行会标记为未计入。

## 价格

`src/prices.ts` 存放价格表：单位为每百万 token 的美元数，并附每个来源的 URL 和核对日期。模型 id 按最长前缀匹配，可限定于某一个提供方；长提示词费率和 DeepSeek 的工作日高峰时段也是条目的一部分。`Config.prices` 会替换同一模型的条目并添加其他条目，因此部署无需发布新版本即可为模型定价。价格表是投影（projection）版本的一部分，所以修改价格会重新计算每个 chat 的数字。

模型不匹配任何条目的请求会被计数，但按未知价格处理，对话框会注明这一点。计算数字时没有任何内容离开本机：插件读取提供方报告的用量，自身不发出任何请求。

## 投影

`costMeter` 是一个会话投影（`src/projection.ts`）：它折叠每个 chat 已保存的历史，从最近的请求头取得模型，并取每次回答或失败尝试所报告的用量，因此重新加载、恢复或 fork 后显示相同的总额，重试的尝试按内置 token 计数的方式计入。它计算的内容不会进入任何模型请求。

会话列表携带每个 chat 的费用，供 studio 汇总 agent 费用；客户端沿父级链接遍历 chat 所启动的各 chat，并在对话框打开时请求尚未见过的 chat。

## 配置

| 字段 | 含义 |
| --- | --- |
| `enabled` | 插件是否运行。默认关闭。 |
| `prices` | 替换或补充内置价格表的条目。设置格式错误会使插件在加载时停止。 |

## 它不建模的内容

批量价格、仅限美国的路由、快速模式、一小时缓存写入、折扣以及 DeepSeek 的假日日历。程序加载的库与此处无关。图标专为 Delorun 的插件列表绘制；修改它需要所有者批准。
