# Agent Note: 每项对模型可见的 Delo 新增内容都有各自的开关，并在对等组合中关闭

Status: implemented

[English](2026-11-06-delo-model-visible-switches.md) | 中文

## 问题

Delo 新增了模型可见的工具、工具描述与提示词文本，例如 `preset_inspect` 工具与 doctor 工具。每项新增内容都会改变模型收到的请求，因此一旦开启，录制下来的上游场景就不再匹配。本人也无法看出哪些新增内容影响了模型的行为，除非每一项都能被找到并关闭。

## 决策

Delo 新增的、模型可见的每个工具、工具描述与提示词文本，都有各自的配置开关。这些开关彼此独立：关闭其中一项不会改变另一项。在对等组合中，所有这类开关都处于关闭状态，因此上游录制的场景所产生的模型请求，与在 stock DSH 中产生的请求相同。

## 验证

录制的上游场景通过 `pnpm run test:snapshot` 回放。在对等组合中，未被关闭的 Delo 新增内容会改变某个录制的请求，从而使回放失败。每个开关都是一个配置字段，审阅者可以在配置中找到每项新增内容的开关。

## 相关决策

对模型可见的新增内容遵循与上游模型可见文本相同的记录规则。[可重建请求决策](../architecture/2026-07-05-reconstructable-requests.zh.md) 要求每个请求都能从会话日志重建，Delo 的新增内容同样受此规则约束。

工具指引遵循 [提示词变量决策](../architecture/2026-07-05-prompt-variables-and-tool-guidance-ownership.zh.md) 的归属规则：每个 Delo 工具拥有自己的描述，每个 Delo 包拥有自己的提示词小节。

[对等决策](../testing/2026-11-06-delo-stock-parity.zh.md) 描述了对等组合，以及使用这些开关的回放。

## 曾考虑的替代方案

**始终开启。** 无法关闭的新增内容会出现在每个请求中，回放因此无法与 stock 匹配，而本人也无法移除不想要的新增内容。

**单一全局开关。** 单个开关会把所有新增内容一起开启或关闭，本人因此无法保留其中一项而移除另一项。

## 后果

每项对模型可见的新增内容都是一个配置字段，对等组合把每个字段都关闭，因此回放会检验每一项新增内容。

新的对模型可见的新增内容随其开关一并引入，对等组合在将其列为差异之前先把该开关关闭。
