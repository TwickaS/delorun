# Governance

## Maintainers

Delo Run maintains Delo. Maintainers review pull requests, merge them, publish releases and handle reports under the [Code of Conduct](CODE_OF_CONDUCT.md) and the [security policy](SECURITY.md). Review requests for the paths listed in [CODEOWNERS](.github/CODEOWNERS) go to the code owners named there.

## Decisions

Maintainers decide which changes Delo merges. A decision about Delo's direction is recorded as an Agent Note in [.agents/notes/](.agents/notes/README.md), which states the decision, its reason, what it gives up and how it is verified. Mechanical and local changes need no Agent Note.

## Becoming a maintainer

Maintainers are people who have made sustained contributions that other maintainers reviewed, and who have been invited by the current maintainers. There is no application process and no fixed number of maintainers. An invitation does not promise a role or a response time, and a maintainer may step down at any time.

## Response times

Delo is a small project. Maintainers review contributions as they can, and Delo does not guarantee a response time for issues, discussions or pull requests.

## Changes to this document

Changes to this document go through pull requests and receive the same review as code.
