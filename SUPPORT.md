# Support

## Documentation

The documentation at [docs.delorun.com](https://docs.delorun.com) explains how to install, set up and use Delorun, and lists the commands and settings. Start there for a question about how something works.

## Questions and problems

- Ask a question or discuss an idea in [GitHub Discussions](https://github.com/Delo-Run/delo/discussions).
- Report a bug or request a feature with the [issue templates](https://github.com/Delo-Run/delo/issues/new/choose). A bug report is most useful with the version from `delorun --version`, the smallest steps that reproduce the problem and the relevant lines of `delorun logs`. Read the logs before you post them and remove anything private.
- Write to support@delorun.com for a question that does not suit an issue or a discussion.

## Security reports

Never report a vulnerability in a public place. Follow [SECURITY.md](SECURITY.md) to report it privately.

## Response times

Delorun is a small project. The maintainers answer as they can and promise no response time ([GOVERNANCE.md](GOVERNANCE.md#response-times)). Only the newest release receives fixes ([SECURITY.md](SECURITY.md#supported-versions)).

## Conduct

Every project space follows the [Code of Conduct](CODE_OF_CONDUCT.md).
