- You can bring the chats you had on chat.deepseek.com into Delorun. Export them from the website, turn on DeepSeek chat import under Plugins, More, then upload the file with the button beside New session; the first-run guide's Recommended plugins step offers the same switch. The plugin is off until you turn it on, and only you at the computer can import.
