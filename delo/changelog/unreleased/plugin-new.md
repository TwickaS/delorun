- `delorun plugin new <name>` creates a plugin folder that builds and installs on the running release: a tool for the agent, an agent preset, a page in the studio's Settings, or a bundle that changes other plugins' settings, chosen with `--kind`. It prints the next commands: build the plugin, check it with `delorun plugin check`, and add it to your profile.
