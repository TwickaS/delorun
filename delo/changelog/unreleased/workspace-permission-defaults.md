---
area: Chats and workspaces
section: Changed
---

- A folder you open now starts on the safer permission, so a chat can write inside it and asks before doing more; turning on full access for a folder takes one answer covering that folder, and a chat whose folder was never answered stays in the sandbox even when something tries to switch it.
- Choosing the safer permission for a folder again withdraws that folder's full-access answer, so turning full access back on asks once more, and puts the folder's other open full-access chats back on the safer permission, in every running profile. A chat picking full access after another profile or `delorun workspace full-access` withdrew it asks again.
