- `delorun changes edit-harness` makes your own copy of the installed Delo's program files and prints its folder. Each file you save, add or delete there is a change to Delo itself that waits for your review in `delorun changes list`, and `show`, `apply`, `discard` and `undo` decide it as they decide a plugin's change, at a terminal. An applied change runs from Delo's next start, beside the installed release, which is never edited and is checked at every start as before; `delorun changes edit-harness --discard` takes every change to Delo itself back, even from a copy Delo can no longer read, and the next start runs the installed release unchanged. A release too large for Delo to read your copy of is refused before anything is copied. When Delo fails to start right after such a change, including when a changed file stops Delo before it starts, it starts once more without it and names it; when it does not start without it either, it names `delorun changes undo <id>` and `delorun changes edit-harness --discard`. Safe mode runs the installed release without any of your changes to it. `delorun verify` and `delorun doctor` list the files you changed and never report a pass when the files Delo would run with your changes differ from what you applied.
