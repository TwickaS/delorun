area: Safety and privacy
section: Security
---

- A plugin's key, a setting the plugin marks as secret such as the DeepSeek API key of web search, is never saved into your profile's settings file, which the profile history keeps in git: saving one from Settings or through the agent is refused with where to put it instead, the history saves no version that holds one, and a start over a settings file that already holds one stops and names the file and the setting, never the key, with how to move it into the credentials file. If an earlier Delo already saved such a key in the profile history, replace the key with a new one.
