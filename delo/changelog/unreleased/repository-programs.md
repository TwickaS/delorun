section: Security
---

- The list of files a turn changed is now read without running any program that the repository's settings, attributes or hooks name, such as a file-system monitor, a filter or a hook, so a command the agent ran cannot plant one there to run later with your full access. The git commands that read it also run inside the chat's sandbox, with no more access than the agent's own commands, and a git older than 2.31 is no longer used for the list. Its working copies now live in your user cache folder, where a sandboxed command cannot write, instead of the temporary folder.
