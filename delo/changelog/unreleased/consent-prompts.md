section: Security
---

- A model-authored write to a skill, a preset, or a workspace's `AGENTS.md` asks for an approval that names the instruction-layer effect, because these instructions load in every future chat, and shows the diff, on every permission preset including full access. It also asks for a write through a linked folder or file, through a hard link to the file itself, for a differently capitalised name on a disk that ignores letter case, and for a write to the profile and home configuration files that hold presets.
- An MCP server that would run as a local command is held until its command is accepted: the exact command with its arguments, its working folder and its environment variables, and the program and folder they lead to on this computer, with the command shell that runs a Windows `.cmd` file, are checked before the server starts. A command that has not been accepted keeps the server stopped and asks again; an accepted command starts that exact program without asking until any of these change, including the folder Delo runs in, its `PATH` or its `COMSPEC`. The request names the environment variables without their values. The check holds whatever order the settings list the server and the consent in, and a command accepted by an earlier build is asked about again.
- Approving a scheduled task names the recurrence it arms, the chat its deliveries reach and the permission preset that chat runs under, and a due delivery refuses, pausing the task, when that chat no longer runs the preset the task was approved under. The approval also names the task, the start of its message and the chat by its title, and for a new chat the folder it opens in and the preset that chat will really start with, such as its workspace's; the task is then held to the preset you were shown. Every occurrence is checked, a task that opens a new chat is checked before the chat exists, so a refused delivery leaves no empty chat behind, and a reminder still waiting from before a restart is checked again before it runs. When the check cannot give a clear answer, nothing is delivered: an answer it does not recognise refuses, and a check that fails keeps the task waiting and reports the failure instead of delivering.
