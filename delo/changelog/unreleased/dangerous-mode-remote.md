- With setup's Dangerous answer on, a phone or browser signed in over remote access, with its unlock running, can do what the computer does: change the settings and plugin rows the computer alone changes with the other answers, run any slash command, loosen the permission new chats start in, answer the questions for MCP servers, external agents and a workspace's network, give the approvals that reserve full access, use terminals, save or remove provider keys (a saved key is never sent back), open a chat's folder in an application on the computer, and read files outside the chat's workspace. A terminal switch or a workspace's full access that a device turns on ends with the mode, while what you set at the computer stays. Only the computer turns the mode on, approves a new device or an unlock, removes a device, changes the remote-access settings or signs a device in. Settings, Permissions now shows `delorun setup prompts` as code in the Dangerous mode card.
