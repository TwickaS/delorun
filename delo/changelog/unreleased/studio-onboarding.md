- The studio's first minute is one short guide that ends in a chat. Welcome sets the language, shows the preview notice and tests each model key with the provider's free model list, so nothing is spent; you can add or change a provider without leaving the guide. Look shows a small chat in the colours you pick. Agents offers Claude Code and Codex, says whether each is signed in on this computer, and asks you to confirm what adding one means: when an agent starts from a chat Delo asks on this computer first unless you allowed it for that workspace, a phone cannot answer, read-only chats never start one, runs stay in the chat's workspace and stop after 30 minutes, and Settings → Permissions revokes it; it runs outside Delo's sandbox with its own sign-in and billing. Recommended plugins puts the plugins that fit your setup first. Phone access, while it is off, checks Tailscale step by step and gives the commands to copy. Workspace opens your first chat in the default workspace, a folder you choose, or a repository cloned from Git; a clone never asks for a password, refuses an address with a sign-in in it, runs none of your Git hooks or filters, shows its progress and says why it failed. Ready lists what you set and opens the chat with starting prompts that fit the folder and fill in the message box for you to send. The studio's own notice about a missing default workspace waits while the guide is open. Settings → General → Getting started shows the guide again. With no working model key, a calm line above the message box says "Add a model key to start chatting" and opens Settings → Models; the studio no longer opens upstream's "Add an API key" dialog.
