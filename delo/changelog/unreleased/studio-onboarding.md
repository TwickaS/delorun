- The studio's first minute is one short guide that ends in a chat. Welcome sets the language, shows the preview notice and tests each model key with the provider's free model list, so nothing is spent; you can add or change a provider without leaving the guide. Look shows a small chat in the colours you pick. Agents offers Claude Code and Codex, says whether each is signed in on this computer, and asks you to confirm what adding one means: Delo's agent may hand it work from any chat without asking first, and it runs outside Delo's sandbox with its own sign-in and billing. Recommended plugins puts the plugins that fit your setup first. Phone access, while it is off, checks Tailscale step by step and gives the commands to copy. Workspace opens your first chat in the default workspace, a folder you choose, or a repository cloned from Git; a clone never asks for a password, shows its progress and says why it failed. Ready lists what you set and opens the chat with starting prompts that fit the folder and fill in the message box for you to send. The studio's own notice about a missing default workspace waits while the guide is open. Settings → About shows the guide again.
