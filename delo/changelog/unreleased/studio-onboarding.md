- The studio's first minute is one short guide that ends in a chat: the preview notice is its first screen, then the language and the look, then the offer to add Claude Code or Codex as agents Delo can hand tasks to (each runs as its own program, with its own permissions), and a last step that opens a new chat with a few starter prompts that fill in the message box for you to send. Where Delo cannot set up a default workspace, the last step asks you to choose a folder and opens the chat there. The studio's own notice about the missing default workspace waits while the guide is open, and shows afterwards only if you skipped the guide before its last step. Settings → About shows the guide again.
