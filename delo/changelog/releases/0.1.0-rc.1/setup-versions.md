- Settings has a Setup versions page that lists the versions Delorun keeps of your setup, newest first, with the current one marked and what made each: an update, a save by you or a switch. Save this setup, with an optional name, keeps a version; What changes shows, in plain words, which plugins, bundles, settings and version exemptions switching to a version would change; Switch to this version saves your current setup as a version first, so switching back is switching to that version, and then tells you to restart Delorun to run it. The page uses the same history as `delorun recover`. Saving and switching work only in the studio on your computer: a phone or other device sees the list and the changes and is told to do it at your computer.
