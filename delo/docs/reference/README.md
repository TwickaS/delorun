# Delo reference

English | [中文](README.zh.md)

Reference pages define current behavior and terms for lookup, without a teaching sequence. The [glossary](glossary.md) defines the words that Delo's documents, interface and pull requests use. It extends upstream's [glossary](../../../docs/glossary.md), which defines the harness's own terms.

The [divergence index](divergence/README.md) defines the ledger of Delo's changes to upstream files, the classes of those changes and the divergence budget.

The [parity checklist](parity.md) records, at the recorded upstream tag `dsh-v0.2.2-rc.1`, the status and evidence of Delo's deliberate differences from stock DSH and of the stock areas they are compared with.

The [parity baseline](parity-baseline.md) records the results of upstream's own test suites on Delo's reference host at the upstream tag: two passes, a Node 24 check, the classification of each remaining failure, and the environment and host state those results depend on.
