# Delo 参考资料

[English](README.md) | 中文

参考资料页面用于查阅，定义现行行为与术语，不设教学顺序。[术语表](glossary.zh.md)定义 Delo 的文档、界面与拉取请求所用的词。它扩展了上游的[术语表](../../../docs/glossary.zh.md)，后者定义 harness 自身的术语。

[差异索引](divergence/README.zh.md)定义 Delo 对上游文件所作修改的台账、这些修改的类别，以及差异预算。

[对等清单](parity.zh.md)在上游记录版本 `dsh-v0.2.2-rc.1` 上记录 Delo 相对 stock DSH 的刻意差异，以及与之对照的 stock 区域的状态与证据。

[对等基线](parity-baseline.zh.md)记录上游自身测试套件在 Delo 参考主机上、于上游标签下的结果：两轮运行、一次 Node 24 核对、每项剩余失败的分类，以及这些结果所依赖的环境与主机状态。
