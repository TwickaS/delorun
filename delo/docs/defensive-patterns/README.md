# Delo defensive patterns

English | [中文](README.zh.md)

Delo's defensive patterns state rules that review enforces in Delo's code, each with the defect it prevents. Upstream's [defensive patterns](../../../docs/defensive-patterns/README.md) apply to Delo as well, and Delo's pages extend them. Delo has no patterns of its own yet.
