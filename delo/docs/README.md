# Delo documentation

English | [中文](README.zh.md)

Delo's documentation is organized in tiers under `delo/docs/`, beside upstream's documentation under `docs/`. Each fact has one home in the tier whose job it is, and other pages link there. Pages about upstream link to upstream's documentation instead of restating it.

- [Guide](guide/README.md): the user guide for people who use Delo, starting with [Delo and stock DeepSeek Harness](guide/delo-vs-stock.md).
- [Cookbook](cookbook/README.md): step-by-step recipes for tasks, each ending in numbered verify steps. None exist yet.
- [Reference](reference/README.md): lookup pages that define current behavior and terms, starting with the [glossary](reference/glossary.md).
- [Defensive patterns](defensive-patterns/README.md): rules that review enforces in Delo's code, extending upstream's [defensive patterns](../../docs/defensive-patterns/README.md). Delo has no patterns of its own yet.
- [Architecture notes](architecture/README.md): the ordered map of Delo's subsystems, with one current-state page for each subsystem. None exist yet.
