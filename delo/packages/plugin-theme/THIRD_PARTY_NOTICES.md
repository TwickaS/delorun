# Third-party notices

This package carries colour data and font files from other projects. Each is listed with its licence and where it is used.

## T3 Code

[`src/palette/t3-themes.ts`](src/palette/t3-themes.ts) holds the colours of T3 Code's six themes, read from `packages/shared/src/themePalettes.ts` at commit `499727ddad87468cc22e23e5d8c92b9013f546c0` by [`scripts/sync-t3-themes.ts`](scripts/sync-t3-themes.ts). [`src/palette/t3.ts`](src/palette/t3.ts) derives the Delo palettes from them, and [`src/client/effort.ts`](src/client/effort.ts) follows T3 Code's effort bars.
